# 02 变量、常量与数据类型

> 学完本篇你将能够：说出 Go 有哪些基本类型、用三种方式声明变量、区分常量和变量、熟练使用四种格式化输出。

## 数据类型

### 字符串

`string`

只能用一对双引号 `""` 或反引号 `` ` `` 括起来定义，**不能用单引号** `''`。

```go
s1 := "双引号\n支持转义"
s2 := `原始字符串
支持多行
不做转义`
```

### 布尔

`bool`

只有 `true` 和 `false`，默认值为 `false`。

### 数字

**整型**：

```text
int8   uint8
int16  uint16
int32  uint32
int64  uint64
int    uint        // 长度取决于 CPU 位数
uintptr            // 无符号整数，足够存放指针
```

**浮点型**：`float32` `float64`

**其他基础类型**：

| 类型 | 说明 |
|---|---|
| `byte` | 别名 `uint8`，常用于字符和文件读写 |
| `rune` | 别名 `int32`，表示一个 Unicode 码点 |
| `complex64` / `complex128` | 复数 |
| `error` | 错误接口，见第 05 篇「错误处理惯例」与第 09 篇「errors 与 fmt」 |

## 常量声明

**常量**，在程序**编译阶段**就确定下来的值，而程序在运行时无法改变该值。

**单个常量声明**，两种写法：

1. `const 变量名称 数据类型 = 变量值`
2. `const 变量名称 = 变量值` —— 根据变量值，自行判断数据类型

> ⚠️ **常量必须初始化**。`const x int`（无表达式）无法通过编译，报 `missing init expr`。
>
> 唯一可以省略表达式列表的场合是**括号分组内**复用上一行的表达式与类型——`iota` 枚举正是靠这条规则实现的（见下文）。
>
> "不赋值取默认值"是**变量**的概念（见下文「零值」），两者不要混讲。

**多个常量声明**，两种写法：

1. `const 变量名称,变量名称 ... ,数据类型 = 变量值,变量值 ...`
2. `const 变量名称,变量名称 ... = 变量值,变量值 ...`

```go
const name string = "Tom"
fmt.Println(name)

const age = 30 // 自动推断为 int
fmt.Println(age)

const name1, name2 string = "Tom", "Jay"
fmt.Println(name1, name2)

const name3, age1 = "Tom", 30
fmt.Println(name3, age1)
```

## 变量声明

**单个变量声明**，三种写法：

1. `var 变量名称 数据类型 = 变量值` —— 不赋值则使用该类型的默认值
2. `var 变量名称 = 变量值` —— 根据变量值，自行判断数据类型
3. `变量名称 := 变量值` —— 省略了 `var` 和数据类型，**变量名称一定要是未声明过的**

**多个变量声明**，三种写法：

1. `var 变量名称,变量名称 ... ,数据类型 = 变量值,变量值 ...`
2. `var 变量名称,变量名称 ... = 变量值,变量值 ...`
3. `变量名称,变量名称 ... := 变量值,变量值 ...`

```go
// 三种声明方式
var age1 uint8 = 31 // 第一种：显式类型
var age2 = 32        // 第二种：自动推断
age3 := 33           // 第三种：短变量声明

// 多变量声明
var age4, age5, age6 int = 31, 32, 33
var name4, age7 = "Tom", 30
name5, isBoy, height := "Jay", true, 180.66
```

> **第 05 篇会用到的一条规则**：`:=` 声明的变量**只在当前作用域内可见**。这直接决定了 `defer` 中参数取值的行为。

## 零值

Go 的变量在声明时若未赋值，会自动取**零值**：

| 类型 | 零值 |
|---|---|
| 数值类型 | `0` |
| 布尔 | `false` |
| 字符串 | `""`（空串） |
| 指针 / slice / map / chan / func / interface | `nil` |

```go
var s string
var b bool
var p *int
fmt.Printf("%q %v %v\n", s, b, p) // "" false <nil>
```

> 与 C/Java 不同，Go **不会**因为使用未初始化的局部变量而编译报错，而是默默赋零值。这是 Go 很少 panic 的原因之一，但也意味着拼写错误会被静默吞掉。

## iota：常量枚举

`iota` 在每个 `const` 块内从 0 开始，每出现一次自动加 1。

```go
type Weekday int

const (
	Sunday Weekday = iota // 0
	Monday                // 1，重复上一行表达式
	Tuesday               // 2
	Wednesday             // 3
)

func (d Weekday) String() string {
	return [...]string{"Sunday", "Monday", "Tuesday", "Wednesday"}[d]
}
```

配合位运算定义权限位（实际开发中最常见的用法）：

```go
const (
	PermRead  = 1 << iota // 0001
	PermWrite             // 0010
	PermExec              // 0100
)

flag := PermRead | PermWrite // 0011
flag&PermRead != 0            // true
```

## 变量交换与丢弃

```go
a, b := 1, 2
a, b = b, a // 直接交换，无需临时变量

a, _ = b, a // 用空白符 _ 丢弃不要的值

_, err := os.Open("f.txt") // 常见用法：只要错误
```

## 四种输出方法

| 方法 | 是否换行 | 是否返回字符串 | 说明 |
|---|---|---|---|
| `fmt.Print` | 否 | 否 | 仅输出 |
| `fmt.Println` | 是 | 否 | 最常用，参数间自动加空格 |
| `fmt.Printf` | 由格式串决定 | 否 | 格式化输出，占位符须与实参**类型匹配** |
| `fmt.Sprintf` | — | **是** | 格式化但不输出，常用于字符串拼接 |

```go
fmt.Print("输出到控制台不换行")
fmt.Println("---")
fmt.Println("输出到控制台并换行")
fmt.Printf("name=%s,age=%d\n", "Tom", 30)
fmt.Printf("name=%s,age=%d,height=%v\n", "Tom", 30, fmt.Sprintf("%.2f", 180.567))

// Sprintf 单独使用
s := fmt.Sprintf("%s-%d", "Tom", 30) // "Tom-30"
```

### 常用格式占位符

| 占位符 | 适用类型 | 补零示例 |
|---|---|---|
| `%v` | 任意类型（自动推断格式） | — |
| `%+v` | 结构体，带字段名 | — |
| `%T` | 打印类型 | — |
| `%d` | 整型 | `%03d` → `031` |
| `%s` | 字符串 | — |
| `%q` | 带引号的字符串 | — |
| `%f` | 浮点 | `%.2f` → `3.14` |
| `%t` | 布尔 | — |
| `%p` | 指针地址 | — |
| `%x` | 十六进制（整型或字符串） | `%02x` |
| `%c` | 字符（rune） | — |
| `%%` | 字面量 `%` | — |

> ⚠️ `Printf` 要求**占位符与实参类型匹配**：`%d` 对整型、`%s` 对字符串（或实现了 `Stringer` 的值）、`%v` 对任意类型。不确定类型时用 `%v` 最安全。
>
> 类型不匹配时，输出中会出现 `%!v(T=value)` 形式的错误标记，例如 `Printf("%s", 30)` 输出 `%!s(int=30)`。注意 `%d` 对**任意整型**（含无符号）都有效，`Printf("%d", 30)` 正常输出 `30`。
>
> 原始教程（02-变量声明.md）中「fmt.Printf 仅输出格式化的字符串和字符串变量（整型和整型变量不可以）」的说法**是错误的**，此处已纠正。

## 本篇要点

1. 变量三种声明：`var x T`、`var x = v`、`x := v`。
2. 常量编译期确定，变量运行时确定；`iota` 用于批量枚举与位标志。
3. Go 会给未初始化的变量赋**零值**，不会编译报错。
4. `Printf` 拼装字符串时用 `Sprintf` 返回值，不要用 `+` 反复拼接（原因见第 08 篇）。
5. `:=` 声明的变量**只在当前作用域内可见**（第 05 篇 defer 会用到）。
6. `Printf` 的占位符与实参类型必须严格匹配。
