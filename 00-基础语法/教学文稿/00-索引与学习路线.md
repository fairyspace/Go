## 三、模块依赖关系（前置知识）

| 文档 | 依赖的前置知识 | 为什么要先学                                                   |
|------|----------------|----------------------------------------------------------------|
| 03   | 02             | 数组元素类型来自变量声明                                       |
| 04   | 02、03         | struct 字段可以是任意基础类型，JSON 解析产出常是 map           |
| 05   | 02、04         | `:=` 的作用域决定 defer 参数取值；结构体传指针决定修改是否生效 |
| 06   | 05             | Options 是「函数 + 闭包 + defer 归还」的组合应用               |
| 07   | 05             | 「defer 只对当前协程有效」是并发必知                           |
| 08   | 03、04、06     | `map[string]interface{}` 慢（04 已预告）、对象池（06 已用到）  |
| 09   | 05             | 时间格式化本质是函数封装                                       |

**三个关键衔接点**：

1. **04 → 08**：`04` 讲 JSON 解析用 `map[string]interface{}` 会有问题，`08` 从性能角度给出同一结论的原因。
2. **06 → 08**：`06` 讲 Options 模式并 **标注了 sync.Pool 池化小对象的反模式**（A16），`08` 讲 Pool 的正确使用场景与 victim
   cache。
3. **05 → 07**：`05` 的「defer 只对当前协程有效」直接决定了「每个 goroutine 都要自己 recover」。
