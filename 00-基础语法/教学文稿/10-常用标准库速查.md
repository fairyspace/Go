## 一、time.RFC3339 时间格式化

### 问题

在开发过程中，我们有时会遇到这样的问题，将 `2020-11-08T08:18:46+08:00` 转成 `2020-11-08 08:18:46`，怎么解决这个问题？

> 解决这个问题，**最好不要用字符串截取**，或者说字符串截取是最笨的方法，这应该是时间格式化的问题。

我们先看一下 golang time 包中支持的 format 格式：

```go
const (
	ANSIC       = "Mon Jan _2 15:04:05 2006"
	UnixDate    = "Mon Jan _2 15:04:05 MST 2006"
	RubyDate    = "Mon Jan 02 15:04:05 -0700 2006"
	RFC822      = "02 Jan 06 15:04 MST"
	RFC822Z     = "02 Jan 06 15:04 -0700" // RFC822 with numeric zone
	RFC850      = "Monday, 02-Jan-06 15:04:05 MST"
	RFC1123     = "Mon, 02 Jan 2006 15:04:05 MST"
	RFC1123Z    = "Mon, 02 Jan 2006 15:04:05 -0700" // RFC1123 with numeric zone
	RFC3339     = "2006-01-02T15:04:05Z07:00"
	RFC3339Nano = "2006-01-02T15:04:05.999999999Z07:00"
	Kitchen     = "3:04PM"
	// Handy time stamps.
	Stamp      = "Jan _2 15:04:05"
	StampMilli = "Jan _2 15:04:05.000"
	StampMicro = "Jan _2 15:04:05.000000"
	StampNano  = "Jan _2 15:04:05.000000000"
)
```

我们找到了 `RFC3339`，那就很简单了，我们封装一个方法 `RFC3339ToCSTLayout`。

> ⚠️ **Go 的时间布局是「参考时间」**：`2006-01-02 15:04:05`（即 Go 官方发布日）对应 Java 的 `yyyy-MM-dd HH:mm:ss`。
>
> - 月 `01`、日 `02`、时 `15`、分 `04`、秒 `05`
> - **小时用 15 而不是 24**，`03` 是 12 小时制的下午 3 点
> - 2006 是年、06 是两位年

### 代码实现

```go
// s11_timeutil/timeutil/timeutil.go
package timeutil

import "time"

var (
	cst *time.Location
)

// CSTLayout China Standard Time Layout
const CSTLayout = "2006-01-02 15:04:05"

func init() {
	var err error
	if cst, err = time.LoadLocation("Asia/Shanghai"); err != nil {
		panic(err)
	}
}

// RFC3339ToCSTLayout convert rfc3339 value to china standard time layout
func RFC3339ToCSTLayout(value string) (string, error) {
	ts, err := time.Parse(time.RFC3339, value)
	if err != nil {
		return "", err
	}

	return ts.In(cst).Format(CSTLayout), nil
}
```

```go
// s11_timeutil/main.go
package main

import (
	"demo/timeutil"
	"fmt"
)

func main() {
	RFC3339Str := "2020-11-08T08:18:46+08:00"
	cst, err := timeutil.RFC3339ToCSTLayout(RFC3339Str)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(cst)
}
```

### 运行一下

输出：

```text
2020-11-08 08:18:46
```

> **为何需要 `init()` 预加载 `time.LoadLocation`**：`time.LoadLocation` 每次调用都要读 IANA 时区数据库（或内嵌的 tzdata），开销不小。预加载为包级变量可避免重复解析。
>
> ⚠️ 若目标环境是精简的 Alpine 容器，需 `import _ "time/tzdata"` 嵌入时区库，或直接用 `time.FixedZone("CST", 8*3600)`。

### 小结

同理，若遇到 `RFC3339Nano`、`RFC822`、`RFC1123` 等格式，也可以使用类似的方法，只需要在 `time.Parse()` 中指定时间格式即可。

## 二、time 常用操作

```go
// 获取当前时间
now := time.Now()
fmt.Println(now)                 // 2026-10-03 15:04:05.999 +0800 CST
fmt.Println(now.Year())          // 2026
fmt.Println(now.Month())         // October
fmt.Println(now.Day())           // 3
fmt.Println(now.Weekday())       // Saturday
fmt.Println(now.YearDay())       // 276
fmt.Println(now.Hour(), now.Minute(), now.Second())

// 时间戳
fmt.Println(now.Unix())      // 秒级，int64
fmt.Println(now.UnixMilli()) // 毫秒级
fmt.Println(now.UnixNano())  // 纳秒级

// 时间戳 → 时间对象
t := time.Unix(1759482245, 0)
fmt.Println(t.Format("2006-01-02 15:04:05"))

// 字符串 → 时间对象
t2, err := time.ParseInLocation("2006-01-02 15:04:05", "2020-11-08 08:18:46", cst)
if err != nil {
	panic(err)
}

// 时间运算
fmt.Println(now.Add(24 * time.Hour))  // 加一天
fmt.Println(now.AddDate(0, 1, 0))    // 加一月
fmt.Println(now.Add(-2 * time.Hour)) // 减两小时
fmt.Println(now.Sub(t2))             // 时间差（Duration）

// 时间比较
if now.After(t2) {
	fmt.Println("now 在 t2 之后")
}
fmt.Println(now.Equal(t2))  // 同一时刻
fmt.Println(now.Before(t2))

// 格式化
const layout = "2006-01-02 15:04:05"
fmt.Println(now.Format(layout))
fmt.Println(now.Format("2006-01-02"))
fmt.Println(now.Format("15:04:05"))
fmt.Println(now.Format(time.RFC3339))
fmt.Println(now.Format("2006年01月02日 15时04分05秒")) // 自定义中文

// 睡眠与超时
time.Sleep(1 * time.Second)
<-time.After(1 * time.Second) // 配合 select 做超时

// 定时器（只触发一次）
timer := time.NewTimer(1 * time.Second)
<-timer.C

// 周期定时器
ticker := time.NewTicker(100 * time.Millisecond)
for range ticker.C {
	fmt.Println("tick")
}
ticker.Stop()
```

### 易错点汇总

| 坑 | 现象 | 正确做法 |
|---|---|---|
| `time.Duration(1)` 被当成 1 纳秒 | 超时逻辑不触发 | 写 `1 * time.Second` |
| `time.Parse` 丢失时区 | 解析结果被当成 UTC | `time.ParseInLocation` 或 `.In(loc)` |
| 服务器时区不可控 | 同一份数据在不同时区显示不同 | 约定统一用 UTC 存储，展示时转换 |
| `Unix()` 返回秒不是毫秒 | 前端时间戳偏差 1000 倍 | 前端要毫秒时用 `UnixMilli()` |
| `Sub` 后再转 Duration 二次丢失精度 | 时间差不准确 | `time.Duration(int64(secs))` 或直接用 Duration |
| RFC3339 与自定义 layout 混用 | 解析失败 | 记住 `2006-01-02T15:04:05Z07:00` |

## 三、strings 常用

```go
s := "Hello, Go World"

strings.Contains(s, "Go")     // true
strings.HasPrefix(s, "Hello") // true
strings.HasSuffix(s, "World") // true
strings.Index(s, "Go")        // 7（首字节索引）
strings.LastIndex(s, "o")     // 8
strings.Count(s, "o")         // 2

strings.Replace(s, "World", "Golang", 2)  // 替换前 2 个
strings.Replace(s, "World", "Golang", -1) // 替换全部
strings.ReplaceAll(s, "o", "0")

strings.Split("a,b,c", ",")     // ["a" "b" "c"]
strings.SplitN("a,b,c", ",", 2) // ["a" "b,c"]
strings.Join([]string{"a", "b"}, "-") // "a-b"

strings.ToUpper(s)
strings.ToLower(s)

strings.TrimSpace("  hi  ")        // "hi"
strings.Trim("xxhixx", "x")        // "hi"
strings.TrimPrefix(s, "Hello, ")   // "Go World"
strings.TrimSuffix(s, "World")     // "Hello, Go "

strings.Fields("a b  c")     // ["a" "b" "c"] 按空白切分
strings.Repeat("ab", 3)      // "ababab"
strings.Title("tom")         // 已废弃，用 golang.org/x/text/cases

// 高效拼接（见第 09 篇）
var sb strings.Builder
sb.Grow(64)
for i := 0; i < 10; i++ {
	sb.WriteString("x")
}
result := sb.String()

// 字符串比较：== 而非 Equals
if s == "Hello, Go World" {
}
```

> **常见坑**：`strings.Split(s, "")` 按 UTF-8 字符切分（正确）；而按字节切分需用 `strings.SplitN` 配合 ASCII 场景。
>
> **零值转换开销**：`strconv.Atoi` 在解析失败时返回 `ErrSyntax`，必须检查 error，否则「0」和「解析失败」无法区分。

## 四、strconv 类型转换

```go
// 字符串 → 数字
i, err := strconv.Atoi("42")               // int
i64, err := strconv.ParseInt("42", 10, 64) // 任意进制与位宽
f, err := strconv.ParseFloat("3.14", 64)   // float64
b, err := strconv.ParseBool("true")        // bool
u, err := strconv.ParseUint("42", 10, 64)  // 无符号

// 数字 → 字符串
s1 := strconv.Itoa(42)
s2 := strconv.FormatInt(42, 10)              // "42"
s3 := strconv.FormatFloat(3.14159, 'f', 2, 64) // "3.14"
s4 := strconv.FormatBool(true)               // "true"

// 进制转换
s5 := strconv.FormatInt(255, 16)     // "ff"
i6, _ := strconv.ParseInt("ff", 16, 64) // 255
```

> `strconv` vs `fmt.Sprintf`：只是格式化数字转字符串时用 `strconv`，更快且无反射；拼接字符串用 `strings.Builder`（第 09 篇）。

## 五、errors 与 fmt

```go
// errors.New 创建固定错误
var ErrNotFound = errors.New("not found")

// fmt.Errorf 创建动态错误，%w 包裹错误链
if err != nil {
	return fmt.Errorf("查询用户 %d 失败: %w", id, err)
}

// errors.Is 判断是否为目标错误（穿透包装）
if errors.Is(err, sql.ErrNoRows) {
	// 处理未找到
}

// errors.As 提取具体错误类型
var pe *os.PathError
if errors.As(err, &pe) {
	fmt.Println(pe.Path)
}

// errors.Join 合并多个错误（Go 1.20+）
err := errors.Join(err1, err2)

// fmt 常用
fmt.Println("a", 1, true)      // a 1 true（参数间自动加空格）
fmt.Printf("%s-%d\n", "a", 1)
fmt.Printf("%+v\n", err)       // 打印结构体字段名与错误链
s := fmt.Sprint("a", 1)        // 返回字符串不输出
```

### 错误处理惯例

- 错误信息用**小写开头**（可被包装后连读），**不加标点结尾**
- 每层只 `fmt.Errorf("上下文: %w", err)` 包装一次，并保留错误链
- **不要用字符串比较判断错误**（`err.Error() == "..."`），要用 `errors.Is`
- 可预期的业务错误定义成**导出变量**（`ErrNotFound`），便于调用方 `errors.Is`

## 本篇要点

1. **Go 时间布局是参考时间** `2006-01-02 15:04:05`，小时是 `15` 不是 `24`。
2. 时间转换的正确姿势是 `time.Parse` + `Format`，**字符串截取是最笨的方法**。
3. `time.LoadLocation` 开销大，用 `init()` 预加载为包级变量；Alpine 容器需 `import _ "time/tzdata"`。
4. 存时间统一用 `Unix()` / `UnixMilli()`，展示时才格式化；跨时区服务统一存 UTC。
5. 字符串拼接用 `strings.Builder` + `Grow`，数字转换用 `strconv`。
6. 错误链用 `%w` 包装 + `errors.Is/As` 提取，**别用字符串比较判断错误**。
7. 定时器分两种：`NewTimer`（一次）和 `NewTicker`（周期），用完记得 `Stop()`。
