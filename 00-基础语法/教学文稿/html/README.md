# Go 代码探险队 · HTML 学习站

这是 `教学文稿/` 的手绘风格静态 HTML 版本。打开 `index.html` 即可从学习地图进入 9 篇课程；每篇都带记忆提示、复述小测、阅读导航，以及已写入页面 HTML 的配套 Go 源码。

## 阅读与生成

- **离线阅读**：直接用浏览器打开 `index.html`；也可从仓库根目录启动静态服务器预览。
- **重新生成章节页**：在仓库根目录执行 `python3 "00-基础语法/教学文稿/build_html.py"`。
- **源文件**：正文以 `../*.md` 为准；代码以 `../../codes/教学/` 为准。编辑源文件后重新运行生成脚本，HTML 里的文稿与代码便会一起更新。
- **依赖**：生成器只使用 Python 标准库；页面样式和交互脚本均为本地文件，不从 CDN 加载。

生成器会输出 `index.html`、路线文稿页 `00-roadmap.html` 与 01—09 篇课程页。页面包含的搜索、复制代码、学习打卡和记忆卡无需联网；浏览器若限制 `file://` 的本地存储，打卡进度可能无法保留，但阅读和代码复制仍可使用。
