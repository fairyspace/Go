02 变量、常量与数据类型

学完本篇你将能够：说出 Go 有哪些基本类型、用三种方式声明变量、区分常量和变量、熟练使用四种格式化输出。

✎ 一句话记住

const 固定不动，var 有零值；:= 是函数里的快捷新朋友。

🧠 30 秒复述变量不赋值会怎样？常量可以只写类型、不写初始值吗？

零值属于变量；常量必须有初始表达式。:= 只能在函数体中使用。

数据类型

string

只能用一对双引号 "" 或反引号 ` 括起来定义，不能用单引号 ''。

常量声明

常量，在程序编译阶段就确定下来的值，而程序在运行时无法改变该值。

单个常量声明，两种写法：

  1. const 变量名称 数据类型 = 变量值
  2. const 变量名称 = 变量值 —— 根据变量值，自行判断数据类型

⚠️ 常量必须初始化。const x int（无表达式）无法通过编译，报 missing init expr。

唯一可以省略表达式列表的场合是括号分组内复用上一行的表达式与类型——iota 枚举正是靠这条规则实现的（见下文）。

"不赋值取默认值"是变量的概念（见下文「零值」），两者不要混讲。

多个常量声明，两种写法：

  1. const 变量名称,变量名称 ... ,数据类型 = 变量值,变量值 ...
  2. const 变量名称,变量名称 ... = 变量值,变量值 ...
GO
const name string = "Tom"
fmt.Println(name)

const age = 30 // 自动推断为 int
fmt.Println(age)

const name1, name2 string = "Tom", "Jay"
fmt.Println(name1, name2)

const name3, age1 = "Tom", 30
fmt.Println(name3, age1)

变量声明

单个变量声明，三种写法：

  1. var 变量名称 数据类型 = 变量值 —— 不赋值则使用该类型的默认值
  2. var 变量名称 = 变量值 —— 根据变量值，自行判断数据类型
  3. 变量名称 := 变量值 —— 省略了 var 和数据类型，变量名称一定要是未声明过的

多个变量声明，三种写法：

  1. var 变量名称,变量名称 ... ,数据类型 = 变量值,变量值 ...
  2. var 变量名称,变量名称 ... = 变量值,变量值 ...
  3. 变量名称,变量名称 ... := 变量值,变量值 ...
GO
// 三种声明方式
var age1 uint8 = 31 // 第一种：显式类型
var age2 = 32        // 第二种：自动推断
age3 := 33           // 第三种：短变量声明

// 多变量声明
var age4, age5, age6 int = 31, 32, 33
var name4, age7 = "Tom", 30
name5, isBoy, height := "Jay", true, 180.66

第 6 篇会用到的一条规则：:= 声明的变量只在当前作用域内可见。这直接决定了 defer 中参数取值的行为。

零值

Go 的变量在声明时若未赋值，会自动取零值：

类型零值
数值类型0
布尔false
字符串""（空串）
指针 / slice / map / chan / func / interfacenil
GO
var s string
var b bool
var p *int
fmt.Printf("%q %v %v\n", s, b, p) // "" false <nil>

与 C/Java 不同，Go 不会因为使用未初始化的局部变量而编译报错，而是默默赋零值。这是 Go 很少 panic 的原因之一，但也意味着拼写错误会被静默吞掉。

iota：常量枚举

iota 在每个 const 块内从 0 开始，每出现一次自动加 1。

GO
type Weekday int

const (
	Sunday Weekday = iota // 0
	Monday                // 1，重复上一行表达式
	Tuesday               // 2
	Wednesday             // 3
)

func (d Weekday) String() string {
	return [...]string{"Sunday", "Monday", "Tuesday", "Wednesday"}[d]
}

配合位运算定义权限位（实际开发中最常见的用法）：

GO
const (
	PermRead  = 1 << iota // 0001
	PermWrite             // 0010
	PermExec              // 0100
)

flag := PermRead | PermWrite // 0011
flag&PermRead != 0            // true

变量交换与丢弃

GO
a, b := 1, 2
a, b = b, a // 直接交换，无需临时变量

a, _ = b, a // 用空白符 _ 丢弃不要的值

_, err := os.Open("f.txt") // 常见用法：只要错误

四种输出方法

方法是否换行是否返回字符串说明
fmt.Print否否仅输出
fmt.Println是否最常用，参数间自动加空格
fmt.Printf由格式串决定否格式化输出，占位符须与实参类型匹配
fmt.Sprintf—是格式化但不输出，常用于字符串拼接
GO
fmt.Print("输出到控制台不换行")
fmt.Println("---")
fmt.Println("输出到控制台并换行")
fmt.Printf("name=%s,age=%d\n", "Tom", 30)
fmt.Printf("name=%s,age=%d,height=%v\n", "Tom", 30, fmt.Sprintf("%.2f", 180.567))

// Sprintf 单独使用
s := fmt.Sprintf("%s-%d", "Tom", 30) // "Tom-30"

常用格式占位符

占位符适用类型补零示例
%v任意类型（自动推断格式）—
%+v结构体，带字段名—
%T打印类型—
%d整型%03d → 031
%s字符串—
%q带引号的字符串—
%f浮点%.2f → 3.14
%t布尔—
%p指针地址—
%x十六进制（整型或字符串）%02x
%c字符（rune）—
%%字面量 %—

⚠️ Printf 要求占位符与实参类型匹配：%d 对整型、%s 对字符串（或实现了 Stringer 的值）、%v 对任意类型。不确定类型时用 %v 最安全。

类型不匹配时，输出中会出现 %!v(T=value) 形式的错误标记，例如 Printf("%s", 30) 输出 %!s(int=30)。注意 %d 对任意整型（含无符号）都有效，Printf("%d", 30) 正常输出 30。

原始教程（02-变量声明.md）中「fmt.Printf 仅输出格式化的字符串和字符串变量（整型和整型变量不可以）」的说法是错误的，此处已纠正。

本篇要点

  1. 变量三种声明：var x T、var x = v、x := v。
  2. 常量编译期确定，变量运行时确定；iota 用于批量枚举与位标志。
  3. Go 会给未初始化的变量赋零值，不会编译报错。
  4. Printf 拼装字符串时用 Sprintf 返回值，不要用 + 反复拼接（原因见第 09 篇）。
  5. := 声明的变量只在当前作用域内可见（第 06 篇 defer 会用到）。
  6. Printf 的占位符与实参类型必须严格匹配。

// s02_var/main.go —— 对应教学文稿 02 变量、常量与数据类型
//
// 运行：go run ./s02_var
package main

import "fmt"

// iota 枚举：每个 const 块内从 0 开始，每出现一次自动加 1
type Weekday int

const (
	Sunday    Weekday = iota // 0
	Monday                   // 1，重复上一行表达式
	Tuesday                  // 2
	Wednesday                // 3
)

func (d Weekday) String() string {
	return [...]string{"Sunday", "Monday", "Tuesday", "Wednesday"}[d]
}

// 配合位运算定义权限位
const (
	PermRead  = 1 << iota // 0001
	PermWrite             // 0010
	PermExec              // 0100
)

func main() {
	// ==================== 常量声明 ====================
	const name string = "Tom"
	fmt.Println(name)

	const age = 30 // 自动推断为 int
	fmt.Println(age)

	const name1, name2 string = "Tom", "Jay"
	fmt.Println(name1, name2)

	const name3, age1 = "Tom", 30
	fmt.Println(name3, age1)

	// ==================== 变量声明 ====================
	// 三种声明方式
	var age2 uint8 = 31 // 第一种：显式类型
	var age3 = 32       // 第二种：自动推断
	age4 := 33          // 第三种：短变量声明（变量必须未声明过）
	fmt.Println(age2, age3, age4)

	// 多变量声明
	var age5, age6, age7 int = 31, 32, 33
	fmt.Println(age5, age6, age7)

	var name4, age8 = "Tom", 30
	fmt.Println(name4, age8)

	name5, isBoy, height := "Jay", true, 180.66
	fmt.Println(name5, isBoy, height)

	// ==================== 零值 ====================
	var s string
	var b bool
	var p *int
	fmt.Printf("零值：%q %v %v\n", s, b, p)

	// ==================== 变量交换与丢弃 ====================
	a, c := 1, 2
	a, c = c, a // 直接交换，无需临时变量
	fmt.Println("交换后：", a, c)

	_, _, d := 1, 2, 3 // 用空白符 _ 丢弃不要的值
	fmt.Println(d)

	// ==================== iota 枚举 ====================
	fmt.Println(Sunday, Monday, Tuesday, Wednesday) // Sunday Monday Tuesday Wednesday

	flag := PermRead | PermWrite
	fmt.Printf("权限位：%b，读=%v，写=%v\n", flag, flag&PermRead != 0, flag&PermWrite != 0)

	// ==================== 四种输出方法 ====================
	fmt.Print("输出到控制台不换行")
	fmt.Println("---")
	fmt.Println("输出到控制台并换行")
	fmt.Printf("name=%s,age=%d\n", "Tom", 30)
	fmt.Printf("name=%s,age=%d,height=%v\n", "Tom", 30, fmt.Sprintf("%.2f", 180.567))

	// Sprintf 单独使用：格式化但不输出
	s2 := fmt.Sprintf("%s-%d", "Tom", 30)
	fmt.Println("Sprintf:", s2)

	// ==================== 类型断言 ====================
	var val interface{} = "go"
	if str, ok := val.(string); ok {
		fmt.Println("断言成功：", str)
	}
}
