## 1. 教学目标

### 1.1 知识目标
1. 能列举 Go 的基本类型，并说出 `byte`/`rune` 分别是谁的别名、为什么需要 `rune`。
2. 能区分**常量**与**变量**的本质差别：常量在编译期求值，变量在运行期占内存。
3. 能说出各类型的**零值**，并解释"零值可用（zero value is useful）"这一 Go 设计哲学。

### 1.2 能力目标
1. 用三种方式声明变量，并能说明各自适用场景。
2. 用 `iota` 写出枚举与位标志两套常量。
3. 正确使用 `Printf` 的常用动词，**看到 `%!d(int=30)` 能立刻定位原因**。

### 1.3 素养目标
1. 养成"能推断就短声明、需明确就写类型"的取舍习惯。
2. 建立"**报错信息就是答案**"的调试观：Go 的格式化错误串自带类型与值。

## 5. 讲授要点（含板书）

### 5.1 板书一：类型地图

```
布尔     bool
整数     int8 int16 int32 int64  /  uint8 uint16 uint32 uint64
         int uint（平台相关，64 位机上通常是 64 位）  uintptr
浮点     float32 float64
复数     complex64 complex128
别名     byte = uint8      （字节、文件 IO）
         rune = int32      （一个 Unicode 码点）
字符串   string（只读字节序列，不是字符数组！）
接口     error（见 06 篇「错误处理惯例」、10 篇「errors 与 fmt」）
```

**字符串两种写法**
```go
s1 := "双引号\n支持转义"       // 解释型字符串
s2 := `反引号
支持多行，不做任何转义`        // 原始字符串，写正则/JSON 模板首选
```

**为什么需要 `rune`**：`"Go语言"` 的 `len()` 是 **8**（字节数），不是 4。要按"字符"遍历必须转 `[]rune` 或用 `for i, r := range s`（`range` 自动按码点解码）。

### 5.2 板书二：常量 vs 变量

```go
// 变量：运行期占内存，有地址，可以改
var a int = 1
a = 2

// 常量：编译期求值，没有地址，不能改
const b = 1
// b = 2   // 编译错误：cannot assign to b
```

**⚠️ 常量必须初始化。**
```go
const x int        // ❌ 编译错误：missing init expr
var   y int        // ✅ y == 0（变量才有零值）
```
唯一能省略表达式的场合是**括号分组内复用上一行**（`iota` 就靠这条规则）：
```go
const (
	A = 1   // 有表达式
	B       // 复用上一行 → 1
	C       // 复用上一行 → 1
)
```

> 讲法建议：把"零值"归给**变量**，把"必须有初始值"归给**常量**，两句话分开说，学生就不会混。（讲义此处写成"常量不赋值取默认值"，是错的——勘误 **A2**。）

**`iota` 的两种典型用法**
```go
// 用法一：枚举
type Weekday int
const (
	Sunday Weekday = iota // 0
	Monday                // 1
	Tuesday               // 2
)

// 用法二：位标志（权限、开关，实际开发更常见）
const (
	PermRead  = 1 << iota // 1
	PermWrite             // 2
	PermExec              // 4
)
flag := PermRead | PermWrite     // 3
hasRead := flag&PermRead != 0    // true
```

**给枚举加 `String()`**
```go
func (d Weekday) String() string {
	names := [...]string{"Sunday", "Monday", "Tuesday"}
	if int(d) < 0 || int(d) >= len(names) {
		return "Unknown"          // ⚠️ 不加这个判断，越界会 panic
	}
	return names[d]
}
```

### 5.3 板书三：零值

| 类型 | 零值 |
|---|---|
| 数值 | `0` |
| 布尔 | `false` |
| 字符串 | `""` |
| 指针 / slice / map / chan / func / interface | `nil` |
| 数组 | 每个元素取各自零值 |
| 结构体 | 每个字段取各自零值 |

```go
var s string
var b bool
var p *int
fmt.Printf("%q %v %v\n", s, b, p)   // "" false <nil>
```

**"零值可用"是 Go 的重要设计**：`var buf bytes.Buffer` 直接能写、`var mu sync.Mutex` 直接能锁、`var sb strings.Builder` 直接能用——不需要构造函数。设计自己的类型时也应尽量做到零值可用。

### 5.4 板书四：四种输出 + 动词表

| 函数 | 换行 | 返回字符串 | 用途 |
|---|---|---|---|
| `fmt.Print` | 否 | 否 | 少用 |
| `fmt.Println` | 是 | 否 | 最常用；参数间自动加空格 |
| `fmt.Printf` | 由格式串决定 | 否 | 格式化输出 |
| `fmt.Sprintf` | — | **是** | 拼字符串（性能见 09 篇） |

| 动词 | 适用 | 示例 |
|---|---|---|
| `%v` | 任意类型（不确定就用它） | `{Tom 30}` |
| `%+v` | 结构体带字段名 | `{Name:Tom Age:30}` |
| `%#v` | Go 语法形式（调试神器） | `main.Person{Name:"Tom", Age:30}` |
| `%T` | 打印类型 | `int` |
| `%d` | **任意整型**（含无符号） | `%03d` → `031` |
| `%s` | 字符串 / `Stringer` | |
| `%q` | 带引号字符串 | `"Tom"` |
| `%f` / `%.2f` | 浮点 | `3.14` |
| `%t` `%p` `%x` `%c` `%%` | 布尔 / 指针 / 十六进制 / 字符 / 百分号 | |

**⚠️ 核心规则：动词必须与实参类型匹配。**
```go
fmt.Printf("%d", 30)      // ✅ 30          —— 整型字面量当然可以直接传！
fmt.Printf("%d", uint8(31)) // ✅ 31        —— %d 对无符号同样有效
fmt.Printf("%s", 30)      // ⚠️ %!s(int=30) —— 动词与类型不匹配
```
`%!s(int=30)` 的读法：**动词 `s` 收到了一个 `int`，值是 30**。报错串自带类型与值，照着改即可。

> **勘误 A1（务必强调）**：网上流传（本仓库讲义也这么写）"`fmt.Printf` 不可以直接传整型字面量"是**错误的**。`%d` 接受任意整型，`Printf("%d", 30)` 输出 `30`。不要教学生写 `fmt.Sprintf("%d", n)` 再打印这种多余代码。

### 5.5 小结（口述六句）
1. 变量三种声明：`var x T`、`var x = v`、`x := v`。
2. **常量必须有初始值**；`iota` 用于枚举与位标志。
3. 变量有**零值**，且"零值可用"是 Go 的设计哲学。
4. `%d` 对任意整型有效；`%!v(T=x)` 是类型不匹配的报错，读它就够了。
5. `:=` 声明的变量**只在当前作用域可见**（06 篇 defer 会用到）。
6. 拼字符串优先 `Sprintf`/`Builder`，别用 `+` 反复累加（09 篇）。

## 6. 演示脚本（先预测，后运行）

```go
package main

import "fmt"

func main() {
	// 预测 1：零值
	var s string
	var p *int
	fmt.Printf("1) %q %v\n", s, p)          // "" <nil>

	// 预测 2：常量复用
	const (
		A = 10
		B
		C
	)
	fmt.Println("2)", A, B, C)              // 10 10 10

	// 预测 3：iota 从 0 开始
	const (
		X = iota
		Y
	)
	fmt.Println("3)", X, Y)                 // 0 1

	// 预测 4：类型不匹配
	fmt.Printf("4) %s\n", 30)               // %!s(int=30)

	// 预测 5：字符串的 len 是字节数
	fmt.Println("5)", len("Go语言"))         // 8
}
```

> 对应仓库示例：`../codes/教学/s02_var/main.go`（`go run ./s02_var`）。

## 7. 课堂练习（含参考答案）

**练习 1** 写出下面代码的输出，并解释原因：
```go
a := 1
{
	a := 2
	fmt.Println("内层", a)
}
fmt.Println("外层", a)
```
> **答**：`内层 2` / `外层 1`。内层 `:=` 声明了一个**新变量**遮蔽了外层同名变量。这正是 06 篇 defer 参数取值问题的根源。

**练习 2** 用 `iota` 定义日志级别 `LevelDebug/Info/Warn/Error`（值为 0,1,2,3），并实现 `String()`。
> **答**：
> ```go
> type Level int
> const (
> 	LevelDebug Level = iota
> 	LevelInfo
> 	LevelWarn
> 	LevelError
> )
> func (l Level) String() string {
> 	names := [...]string{"DEBUG", "INFO", "WARN", "ERROR"}
> 	if int(l) < 0 || int(l) >= len(names) {
> 		return "UNKNOWN"
> 	}
> 	return names[l]
> }
> ```

**练习 3** 用位标志定义权限 `Read=1 Write=2 Exec=4`，写一个函数 `Has(perm, target int) bool`。
> **答**：`func Has(perm, target int) bool { return perm&target == target }`（注意是 `== target` 而不是 `!= 0`，才能校验"同时具备多个权限"）。

**练习 4** 解释：为什么 `fmt.Printf("%d", 30)` 合法，而 `fmt.Printf("%s", 30)` 输出 `%!s(int=30)`？后者为什么不是编译错误？
> **答**：`Printf` 的形参是 `...interface{}`（`...any`），任何类型都能传进去，**编译期无法检查动词与实参是否匹配**，只能在运行期发现并打印 `%!s(int=30)`。`go vet` 的 `printf` 检查能在静态阶段捕获其中一部分（这也是 `go test` 默认跑 vet 的价值）。

## 8. 勘误与易错预警

| 编号 | 讲义原说法 | 正确说法 |
|---|---|---|
| **A1** | `fmt.Printf` 整型字面量不可以直接传 | **可以**。`%d` 接受任意整型。只有动词与类型不匹配才会得到 `%!x(T=v)` |
| **A2** | 常量不赋值则取该类型默认值 | 常量**必须初始化**，`const x int` 编译报错 `missing init expr`；零值是**变量**的机制 |
| **A18** | `error` 见第 10 篇详述 | 见 **06 篇**「错误处理惯例」与 10 篇「errors 与 fmt」 |
| — | `int` 长度取决于 CPU 位数 | 更准确：**平台相关**，64 位平台上是 64 位；需要确定宽度时用 `int32/int64` |
| — | 学员常写 `s[len(s)]` | 下标从 0 开始，最后一个是 `s[len(s)-1]`；越界 panic `index out of range` |
