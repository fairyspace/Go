## 1. 教学目标

### 1.1 知识目标
1. 能记住 Go 的时间布局是**参考时间** `2006-01-02 15:04:05`，并说出各数字的来历。
2. 能说出 `time.Parse` 与 `time.ParseInLocation` 的差别，以及什么时候结果会"变成 UTC"。
3. 能说出错误处理的四条惯例，并区分 `errors.Is` 与 `errors.As` 的用途。

### 1.2 能力目标
1. 封装一个可复用的时间工具包（预加载时区、支持多种输入格式）。
2. 用 `errors.Join` / `%w` / `errors.Is` 组织多层错误。
3. 在 `strings` / `strconv` / `slices` / `maps` 之间选对工具。

### 1.3 素养目标
1. **错误信息小写开头、不加标点**——因为它会被上层包装后连读。
2. **不要用字符串比较判断错误**（`err.Error() == "..."`）——用 `errors.Is`。
3. 存储用 UTC / 时间戳，展示时才转本地时区。

## 5. 讲授要点（含板书）

### 5.1 板书一：时间布局是"参考时间"

```
2006-01-02 15:04:05
 │    │  │  │  │  │
 年   月 日 时 分 秒        （美式顺序 1 2 3 4 5，年 2006，时区 -0700 → 记忆为 1 2 3 4 5 6 7）
```

| 布局片段 | 含义 |
|---|---|
| `2006` / `06` | 四位年 / 两位年 |
| `01` | 月（**不是** `mm`） |
| `02` | 日 |
| `15` | **24 小时制**的小时（`03` 是 12 小时制） |
| `04` / `05` | 分 / 秒 |
| `Z07:00` | ISO 8601 时区（RFC3339 用） |
| `.000` / `.999` | 毫秒（`.000` 固定补零，`.999` 去尾零） |

```go
const layout = "2006-01-02 15:04:05"
time.Now().Format(layout)
time.Now().Format(time.RFC3339)              // 2006-01-02T15:04:05Z07:00
time.Now().Format("2006年01月02日 15时04分05秒")
```

**常用常量**：`time.ANSIC`、`time.RFC3339`、`time.RFC3339Nano`、`time.RFC1123`、`time.Kitchen`、`time.Stamp*`。

### 5.2 板书二：时区的三个坑

```go
// 坑 1：layout 里没有时区信息 → 结果按 UTC 解释
t, _ := time.Parse("2006-01-02 15:04:05", "2020-11-08 08:18:46")
fmt.Println(t)                                  // 2020-11-08 08:18:46 +0000 UTC
t2, _ := time.ParseInLocation("2006-01-02 15:04:05", "2020-11-08 08:18:46", cst)
fmt.Println(t2)                                 // ... +0800 CST

// 坑 2：layout 里**有**时区信息 → Parse 会正确解析偏移
t3, _ := time.Parse(time.RFC3339, "2020-11-08T08:18:46+08:00")
fmt.Println(t3.Unix())                          // 与 +00:00 版本相差 8 小时
```
> 讲义说"`time.Parse` 丢失时区"**不严谨**：只有当 **layout 不含时区信息**时，结果才按 UTC 解释；`time.Parse(time.RFC3339, ...)` 会正确解析 `+08:00`。规则是"看 layout 有没有时区位"，不是"Parse 一定丢时区"。

```go
// 坑 3：Unix() 返回秒，前端常要毫秒
time.Now().Unix()       // 秒
time.Now().UnixMilli()  // 毫秒
time.Now().UnixNano()   // 纳秒
```

**工程约定**：**存储用 UTC 或时间戳，展示时才转本地时区。**

### 5.3 板书三：封装 timeutil

```go
// timeutil/timeutil.go
package timeutil

import "time"

const CSTLayout = "2006-01-02 15:04:05"

var cst *time.Location

func init() {
	loc, err := time.LoadLocation("Asia/Shanghai")
	if err != nil {
		// 讨论点：init 里 panic 会让"导入这个包"就崩溃。
		// 折中方案：降级为固定时区，并记录一条日志。
		loc = time.FixedZone("CST", 8*3600)
	}
	cst = loc
}

func RFC3339ToCSTLayout(value string) (string, error) {
	ts, err := time.Parse(time.RFC3339, value)
	if err != nil {
		return "", err
	}
	return ts.In(cst).Format(CSTLayout), nil
}

func UnixToCSTLayout(sec int64) string {
	return time.Unix(sec, 0).In(cst).Format(CSTLayout)
}
```
**两个工程要点**
1. `time.LoadLocation` 要读 IANA 时区库，**预加载为包级变量**避免重复开销。
2. 精简的 Alpine 容器可能没有 tzdata：`import _ "time/tzdata"` 把时区库编进二进制，或用 `time.FixedZone` 兜底。
3. **`init()` 里 panic 是危险设计**：它让"导入包"这个动作就能让进程起不来不了。教学示例可以，生产代码建议降级 + 日志。

### 5.4 板书四：错误处理

```go
// 1) 哨兵错误：可被调用方 errors.Is 识别
var ErrNotFound = errors.New("not found")

// 2) 包装：加上下文，保留错误链
if err != nil {
	return fmt.Errorf("查询用户 %d 失败: %w", id, err)
}

// 3) 判断
if errors.Is(err, ErrNotFound) { /* ... */ }

// 4) 提取具体类型
var pe *os.PathError
if errors.As(err, &pe) {
	fmt.Println(pe.Path)
}

// 5) 合并多个错误（Go 1.20+）
err := errors.Join(err1, err2)      // 任一为 nil 会被忽略；全 nil 返回 nil
```

**四条惯例**
1. 错误信息**小写开头、不加标点**（会被包装后连读：`查询用户失败: not found`）。
2. 每层**只包装一次**，且用 `%w` 保留链路。
3. **不要用字符串比较判断错误**，用 `errors.Is`。
4. 可预期的业务错误定义成**导出的哨兵变量**或自定义类型。

```go
// 自定义错误类型（携带结构化信息）
type ValidationError struct {
	Field string
	Msg   string
}
func (e *ValidationError) Error() string {
	return fmt.Sprintf("字段 %s 校验失败: %s", e.Field, e.Msg)
}
// 调用方：
var ve *ValidationError
if errors.As(err, &ve) {
	showFieldError(ve.Field, ve.Msg)
}
```

### 5.5 板书五：标准库速查（含现代 API）

**strings**
```go
s := "Hello, Go World"     // 下标：H0 e1 l2 l3 o4 ,5 ␠6 G7 o8 ␠9 W10 o11 r12 l13 d14

strings.Contains(s, "Go")      // true
strings.Index(s, "Go")         // 7
strings.LastIndex(s, "o")      // 11  ← 勘误 A5（讲义写 8）
strings.Count(s, "o")          // 3   ← 勘误 A5（讲义写 2）

strings.Split("a,b,c", ",")      // [a b c]
strings.SplitN("a,b,c", ",", 2)  // [a b,c]
strings.Join([]string{"a", "b"}, "-")  // a-b
strings.Fields("a b  c")         // [a b c]（按空白切分）

strings.TrimSpace("  hi  ")      // hi
strings.TrimPrefix(s, "Hello, ") // Go World
strings.ReplaceAll(s, "o", "0")

var sb strings.Builder           // 高效拼接（09 篇）
sb.Grow(64)
sb.WriteString("x")
_ = sb.String()

// strings.Title 已废弃 → golang.org/x/text/cases
```

**strconv**
```go
i, err := strconv.Atoi("42")                  // 失败返回 *NumError（可用 errors.Is(err, strconv.ErrSyntax) 判断）
i64, err := strconv.ParseInt("42", 10, 64)
f, err := strconv.ParseFloat("3.14", 64)
b, err := strconv.ParseBool("true")

s1 := strconv.Itoa(42)                        // "42"
s2 := strconv.FormatInt(255, 16)              // "ff"
s3 := strconv.FormatFloat(3.14159, 'f', 2, 64) // "3.14"
```
> 只做"数字 ↔ 字符串"就用 `strconv`，比 `fmt.Sprintf` 快且无反射。

**Go 1.21+ 应该替换的旧写法**
| 旧 | 新（最低版本） |
|---|---|
| `sort.Ints(s)` / `sort.Strings(s)` | `slices.Sort(s)`（1.21） |
| `sort.Slice(s, less)` | `slices.SortFunc(s, cmp)`（1.21） |
| 手写 `Contains` / `Index` | `slices.Contains` / `slices.Index`（1.21） |
| 手写 map 的 key 收集 | `maps.Keys(m)`（1.21 返回 `[]K`；**1.23 起返回类型改为迭代器 `iter.Seq[K]`**，可直接 `for k := range maps.Keys(m)`，要切片用 `slices.Collect`） |
| 收集 key 再排序 | `slices.Sorted(maps.Keys(m))`（1.23+，一行搞定"有序遍历 map"） |
| 手写 min/max | 内置 `min(a, b)` / `max(a, b)`（1.21） |
| 循环置零 / 清空 map | 内置 `clear(s)` / `clear(m)`（1.21） |
| `for i := 0; i < n; i++` | `for i := range n`（1.22） |
| `math/rand` + 手动 Seed | `math/rand/v2`（1.22，无需 Seed） |
| 手写字符串遍历解析 | `for range` over func 迭代器（1.23） |

| 包 | 关键 API |
|---|---|
| `fmt` | `Println` `Printf` `Sprintf` `Errorf` |

| `slices` / `maps` | `Sort` `Contains` `Clone` / `Keys` `Values` `Clone` |

## 6. 演示脚本

```go
package main

import (
	"errors"
	"fmt"
	"slices"
	"strconv"
	"strings"
	"time"
)

var ErrNotFound = errors.New("not found")

func findUser(id int) error {
	if id <= 0 {
		return fmt.Errorf("非法 id %d: %w", id, ErrNotFound)
	}
	return nil
}

func main() {
	// 1) strings 的正确结果（勘误 A5）
	s := "Hello, Go World"
	fmt.Println("1)", strings.Index(s, "Go"), strings.LastIndex(s, "o"), strings.Count(s, "o"))
	// 7 11 3

	// 2) 时间格式
	const layout = "2006-01-02 15:04:05"
	t1, _ := time.Parse(layout, "2020-11-08 08:18:46")
	fmt.Println("2) 无时区信息 →", t1)                 // +0000 UTC
	t2, _ := time.Parse(time.RFC3339, "2020-11-08T08:18:46+08:00")
	fmt.Println("   有时区信息 →", t2, t2.Unix())

	// 3) 错误链
	err := findUser(0)
	fmt.Println("3)", err)                              // 非法 id 0: not found
	fmt.Println("   errors.Is(ErrNotFound):", errors.Is(err, ErrNotFound))

	// 4) errors.Join
	e1 := errors.New("a")
	e2 := errors.New("b")
	joined := errors.Join(e1, e2)
	fmt.Println("4)", joined, "| Is(e1):", errors.Is(joined, e1))

	// 5) 现代 API
	nums := []int{3, 1, 2}
	slices.Sort(nums)
	fmt.Println("5)", nums, slices.Contains(nums, 2), min(1, 2), max(1, 2))

	m := map[string]int{"a": 1, "b": 2}
	keys := make([]string, 0, len(m))
	for k := range m {
		keys = append(keys, k)
	}
	slices.Sort(keys)
	fmt.Println("   keys:", keys, "len:", len(m))
	clear(m)
	fmt.Println("   clear 后:", len(m))

	// 6) strconv
	n, err := strconv.Atoi("42")
	fmt.Println("6)", n, err)
	_, err = strconv.Atoi("x")
	fmt.Println("   解析失败:", errors.Is(err, strconv.ErrSyntax))

	// 7) for i := range n（Go 1.22+）
	for i := range 3 {
		fmt.Print("7)", i, " ")
	}
	fmt.Println()
}
```

> 对应仓库示例：`s11_timeutil/`。

## 7. 课堂练习（含参考答案）

**练习 1** 把 `2020-11-08T08:18:46+08:00` 转成 `2020/11/08 08:18:46`，再转成北京时间字符串。
> **答**：
> ```go
> t, err := time.Parse(time.RFC3339, "2020-11-08T08:18:46+08:00")
> if err != nil { return err }
> s := t.In(cst).Format("2006-01-02 15:04:05")   // 2020-11-08 08:18:46
> ```

**练习 2** 下面代码为什么输出 `+0000 UTC`？两种改法。
```go
t, _ := time.Parse("2006-01-02 15:04:05", "2020-11-08 08:18:46")
```
> **答**：layout 中没有时区信息，`Parse` 按 UTC 解释。改法一：`time.ParseInLocation(layout, value, time.Local)`；改法二：让上游传带时区的 RFC3339 字符串（**推荐**，跨服务不留歧义）。

**练习 3** 实现 `func JoinErrors(errs ...error) error`，要求全为 nil 时返回 nil，并写单测。（提示：直接用 `errors.Join`，重点是理解它的 nil 处理。）
> **答**：
> ```go
> func JoinErrors(errs ...error) error { return errors.Join(errs...) }
> ```
> 单测三点：全 nil → nil；部分 nil → 只含非 nil；`errors.Is` 能穿透命中任一子错误。

**练习 4** 把下面代码用 Go 1.21+ 的 API 重写，并说明收益。
```go
sort.Slice(users, func(i, j int) bool { return users[i].Age < users[j].Age })
found := false
for _, u := range users { if u.Name == "Tom" { found = true; break } }
```
> **答**：
> ```go
> slices.SortFunc(users, func(a, b User) int { return a.Age - b.Age })
> found := slices.ContainsFunc(users, func(u User) bool { return u.Name == "Tom" })
> ```
> 收益：更短、意图更清晰；`SortFunc` 用 `cmp` 语义避免 `a-b` 溢出时应改用 `cmp.Compare(a.Age, b.Age)`（**这是 `a-b` 写法的一个真实坑**）。

## 8. 勘误与易错预警

| 编号 | 讲义原状 | 正确说法 |
|---|---|---|
| **A5** | `LastIndex(s,"o") // 8`、`Count(s,"o") // 2` | **11** 和 **3**（`o` 在下标 4、8、11） |
| — | "`time.Parse` 丢失时区" | 只有 **layout 无时区信息**时才按 UTC 解释；`Parse(time.RFC3339, ...)` 正确解析偏移 |
| — | `init()` 里 `panic` | 生产代码建议降级（`FixedZone`）+ 日志，避免"导入即崩" |
| — | `strconv.Atoi` 失败返回 `ErrSyntax` | 返回的是 `*NumError`，**包装了** `ErrSyntax`；要用 `errors.Is` 判断 |
| — | `strings.Split(s, "")` "按 UTF-8 字符切分" | 正确，但更推荐 `[]rune(s)` 或 `for i, r := range s` 表达同样意图 |
| — | 速查表只有 `sort` | 补 `slices`/`maps`/`min`/`max`/`clear`（Go 1.21+）与 `for i := range n`（1.22+） |
| — | 学员用 `err.Error() == "not found"` | 用 `errors.Is(err, ErrNotFound)`；字符串比较在包装后立即失效 |
