## 1. 教学目标

### 1.1 知识目标
1. 能说出 `range` 遍历 array / slice / map / string / channel 时分别得到什么。
2. 能说出 **`range` 的 value 是副本**，并解释"改副本"与"改原容器"的区别。
3. 能说出 Go `switch` 与 C 的两个关键差异：**默认不穿透**、**case 可以是任意表达式**。

### 1.2 能力目标
1. 按"要不要 value"选择最省的遍历写法。
2. 用标签 `break L` / `continue L` 跳出多层循环。
3. 用类型 switch 分派不同类型。

### 1.3 素养目标
1. **业务代码不写 `goto`**；理解它存在的意义（编译器生成的错误处理路径、极端场景的清理跳转）。
2. 优先用 `switch` 替代长 `if-else if` 链。

## 5. 讲授要点（含板书）

### 5.1 板书一：遍历的三种写法

```go
s := []string{"Tom", "Aaron", "John"}

for i, v := range s { _ = i; _ = v }   // ① 要下标也要值
for i := range s { _ = s[i] }          // ② 只要下标（不复制元素）
for i := 0; i < len(s); i++ { _ = s[i] } // ③ 三段式（需要控制步长/中途改长度时）
for _, v := range s { _ = v }          // ④ 只要值
```

**选择依据**
| 需求 | 写法 |
|---|---|
| 只用值 | ④ |
| 只用下标，或元素是**大 struct**（避免每轮复制） | ② |
| 需要同时改长度、或倒序、或跳步 | ③ |
| 遍历 map | 只能 `range`（map 没有下标） |

```go
// map 的三种遍历
for k, v := range m { }   // 键值
for k := range m { }      // 只要键
for _, v := range m { }   // 只要值
```
> ⚠️ map 遍历**顺序随机**，需要稳定顺序先收集 key 再 `slices.Sort`（03 篇）。

**`range` 遍历 string**：按 **UTF-8 码点**解码，`i` 是字节下标，`r` 是 `rune`：
```go
for i, r := range "Go语言" {
	fmt.Println(i, string(r))   // 0 G / 1 o / 2 语 / 5 言
}
```

### 5.2 板书二：`range` 的值是副本

```go
s := []int{1, 2, 3}

for _, v := range s {
	v = 99          // ❌ 只改了副本
}
fmt.Println(s)      // [1 2 3]

for i := range s {
	s[i] = 99       // ✅ 改原切片
}
fmt.Println(s)      // [99 99 99]
```
同理，`for _, u := range users { u.Age++ }` **不会**修改 `users`；要改必须 `users[i].Age++`，或用 `for i := range users`。

**Go 1.22 的变化**（必讲）
```go
// Go 1.21 及以前：所有闭包共享同一个 i → 可能全打印 3
// Go 1.22 起：每轮迭代 i 是新变量 → 打印 1 2 3（顺序不定）
for i := 1; i <= 3; i++ {
	go func() { fmt.Println(i) }()
}
```
> 讲法：**新代码不需要再写 `i := i`**；但读老代码时会看到这种写法，要能认出它在解决什么问题。`go.mod` 里的 `go 1.xx` 指令决定用哪种语义——这就是它的作用之一。

### 5.3 板书三：break / continue / goto

```go
for i := 1; i <= 10; i++ {
	if i == 6 { break }      // 跳出当前循环（只跳一层）
	if i == 3 { continue }   // 跳过本轮
}
```

**多层跳出用标签**
```go
outer:
for i := 0; i < 3; i++ {
	for j := 0; j < 3; j++ {
		if i == 1 && j == 1 {
			break outer      // 直接跳出外层
		}
	}
}
```
- `break` 可用于 `for` / `switch` / `select`。
- `continue` **只能用于 `for`**。
- Go **没有** PHP 的 `continue 2`，多层用标签。

**goto**
```go
for i := 1; i <= 10; i++ {
	if i == 6 { goto END }
	fmt.Println(i)
}
END:
fmt.Println("end")
```
- 只能在**同一函数内**跳转，且**不能跳过变量声明**（跳进一个变量的作用域是编译错误）。
- **业务代码不要用**。它的合法用途是：需要一处集中清理、且清理逻辑在多层嵌套的最外层（标准库里有极少量这种写法）。
- 讲义里"Go 编译器生成代码时大量使用 goto"这类说法**不要当知识点讲**——它既无法验证，也不是学生需要掌握的内容。

### 5.4 板书四：switch 的四种形态

```go
// ① 值匹配：默认不穿透，不需要 break
switch i {
case 1:
	fmt.Println("one")
case 2, 3:                 // 一个 case 多个值
	fmt.Println("two or three")
default:
	fmt.Println("other")
}

// ② fallthrough：无条件执行"下一个 case"的语句（不看它的条件）
switch i {
case 1:
	fmt.Println("1")
	fallthrough
case 2:                    // 即使 i != 2 也会执行这里
	fmt.Println("2")
}

// ③ 无表达式 switch：替代 if-else if 链
switch {
case score >= 90:
	grade = "A"
case score >= 60:
	grade = "B"
default:
	grade = "C"
}

// ④ 类型 switch
switch v := i.(type) {
case int:
	fmt.Println("int", v)
case string:
	fmt.Println("string", len(v))
case error:
	fmt.Println("error", v.Error())
case nil:
	fmt.Println("nil")
default:
	fmt.Printf("未知 %T\n", v)
}
```

**四条规则**
1. 每个 case 结束**隐式 break**（与 C 相反）。
2. `case` 可以有多个值，用逗号分隔。
3. `fallthrough` 把控制权交给**紧邻的下一个 case**，并且**不判断**它的条件；要连续穿透就每个 case 都写。
4. 类型 switch 中 `v` 在每个 case 内是**该 case 的具体类型**；**按书写顺序匹配**，先宽后窄是常见 bug（宽接口会吃掉窄类型）。

**结构提醒**（讲义问题）：讲义把进阶用法写成"三种"却列了四条，其中一条标题写"标签穿透到 case 上"但代码里没有任何标签。教案统一为**四种形态**（值 / fallthrough / 无表达式 / 类型），标签只属于 `break`/`continue`。

### 5.5 小结（口述六句）
1. 遍历：要值用 `for _, v`，只要下标或元素大用 `for i`，map 只能 `range`。
2. `range` 的 value 是**副本**，改原容器要 `s[i] = x`。
3. Go 1.22 起循环变量每轮独立，老代码里的 `i := i` 是历史产物。
4. `break` 跳一层，多层用标签；`continue` 只用于 `for`；`goto` 不进业务代码。
5. `switch` 默认不穿透、支持多值 case、支持无表达式与类型 switch。
6. 类型 switch **按顺序匹配**，把窄类型写在前面。

## 6. 演示脚本

```go
package main

import "fmt"

func main() {
	// 1) 改副本 vs 改原切片
	s := []int{1, 2, 3}
	for _, v := range s {
		v *= 10
	}
	fmt.Println("1) 改副本:", s) // [1 2 3]
	for i := range s {
		s[i] *= 10
	}
	fmt.Println("   改原值:", s) // [10 20 30]

	// 2) range string 按码点
	for i, r := range "Go语言" {
		fmt.Printf("2) 字节下标=%d 字符=%s\n", i, string(r))
	}

	// 3) fallthrough
	for i := 1; i <= 4; i++ {
		fmt.Print("3) i=", i, " → ")
		switch i {
		case 1:
			fmt.Print("one ")
			fallthrough
		case 2:
			fmt.Print("two ")
		case 3:
			fmt.Print("three ")
		default:
			fmt.Print("other ")
		}
		fmt.Println()
	}
	// i=1 → one two   （穿透到下一个 case，不判断 i==2）
	// i=2 → two
	// i=3 → three
	// i=4 → other

	// 4) 标签跳出多层
outer:
	for i := 0; i < 3; i++ {
		for j := 0; j < 3; j++ {
			if i == 1 && j == 1 {
				fmt.Println("4) 跳出于", i, j)
				break outer
			}
		}
	}

	// 5) 类型 switch
	for _, v := range []any{1, "go", []int{1, 2}, nil, 3.14} {
		describe(v)
	}
}

func describe(i any) {
	switch v := i.(type) {
	case int:
		fmt.Println("5) int:", v)
	case string:
		fmt.Println("5) string 长度:", len(v))
	case []int:
		fmt.Println("5) []int 长度:", len(v))
	case nil:
		fmt.Println("5) nil")
	default:
		fmt.Printf("5) 未知类型 %T\n", v)
	}
}
```

> 对应仓库示例：`s07_loop/main.go`。

## 7. 课堂练习（含参考答案）

**练习 1** 下面代码输出什么？为什么？
```go
users := []struct{ Name string; Age int }{{"Tom", 30}, {"Jay", 20}}
for _, u := range users {
	u.Age++
}
fmt.Println(users)
```
> **答**：`[{Tom 30} {Jay 20}]`，年龄没变。`u` 是每轮复制出来的副本。要改成 `for i := range users { users[i].Age++ }`。

**练习 2** 用**一个** `for` + 标签，打印九九乘法表并在 `i*j > 30` 时整体停止。
> **答**：
> ```go
> outer:
> for i := 1; i <= 9; i++ {
> 	for j := 1; j <= i; j++ {
> 		if i*j > 30 {
> 			break outer
> 		}
> 		fmt.Printf("%d*%d=%d ", j, i, i*j)
> 	}
> 	fmt.Println()
> }
> ```

**练习 3** 把下面的 `if-else if` 链改写成无表达式 switch，并说明好处。
```go
if code >= 500 { level = "error" } else if code >= 400 { level = "warn" } else { level = "info" }
```
> **答**：
> ```go
> switch {
> case code >= 500:
> 	level = "error"
> case code >= 400:
> 	level = "warn"
> default:
> 	level = "info"
> }
> ```
> 好处：① 不会因为忘记 `break` 而贯穿；② 分支边界对齐、可读性更好；③ 加 `default` 时编译器/审查者更容易发现遗漏。

**练习 4** 下面类型 switch 有什么问题？
```go
switch v := x.(type) {
case fmt.Stringer:
	fmt.Println("Stringer:", v.String())
case *User:
	fmt.Println("User:", v.Name)
}
```
> **答**：如果 `*User` 实现了 `String()`，第一个 case 会先命中，`case *User` 永远走不到。**窄类型写在前面**：先 `case *User`，再 `case fmt.Stringer`。

## 8. 勘误与易错预警

| 项 | 讲义原状 | 教案处理 |
|---|---|---|
| 结构 | "switch 的三种进阶用法"下实际列了 4 条 | 统一为**四种形态**：值 / fallthrough / 无表达式 / 类型 |
| 标题 | 第 3 条"标签穿透到 case 上"，代码里无标签 | 删除该条；标签只与 `break`/`continue` 相关，单列一节 |
| `goto` | "Go 编译器生成代码时会大量使用它" | 不作为知识点；改为"不能跳过变量声明"这一可验证的规则 |
| 循环变量 | 只提到"Go 1.22 之前必须手动复制" | 补充：`go.mod` 的 `go` 指令决定语义，读老代码要认得 `i := i` |
| — | 学员常写 `for i := 1; i <= len(s); i++` | 下标从 0 开始，正确是 `i < len(s)` |
| — | 学员在 `switch` 里写 `break` | 多余（默认就 break）；需要穿透时用 `fallthrough` |
