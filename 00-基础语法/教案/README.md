## 一、这个目录解决什么问题

原 `../教学文稿/` 是一份**组织得不错的讲义**，但存在两类问题：

1. **20 处技术性错误**——其中 4 处会让学生形成错误的心智模型（详见下表），另有 12 处工程一致性问题和 7 处教学法缺陷；
2. **它不是教案**——没有课时、教学目标、重难点、教学流程、课堂练习、考核点，教师拿到手无法直接上课。

本目录同时解决这两件事：**每篇都是可直接上课的教案**，且**每一处与讲义不同的说法都在 §8「勘误」中标注了依据**。

### 必须先知道的 4 个高危错误

| 编号 | 讲义原说法 | 事实 | 详见 |
|---|---|---|---|
| **A1** | `fmt.Printf` 不能直接传整型字面量 | `fmt.Printf("%d", 30)` 正常输出 `30`；`%d` 接受任意整型 | `02` §5.4 |
| **A6** | goroutine 是线程；Go 只并发不并行 | goroutine 是运行时调度的用户态单元（GMP）；`GOMAXPROCS` 默认等于核数，**Go 既并发也并行** | `08` §5.1 |
| **A7** | 传值 `sync.WaitGroup` 会 panic | **不会 panic**。`noCopy` 只给 `go vet` 看；真实后果是 `Wait()` 永久阻塞 | `08` §5.5 |
| **A8** | 编译器会把循环里的 `s += x` 改写成 `strings.Builder` | **不会**。跨迭代累加仍是 O(n²)；讲义自己的 `999 allocs/op` 就是反证 | `09` §5.2 |

完整清单（A1~A20 / B1~B12 / C1~C7）见 **[`00-审阅报告.md`](00-审阅报告.md)**。

## 三、每篇教案的统一结构

```
1. 教学目标（知识 / 能力 / 素养）     ← 可判定，不写"了解""熟悉"
2. 重点与难点 + 处理方式
3. 课前准备
4. 教学流程（分钟级时间轴）
5. 讲授要点（含板书设计）
6. 演示脚本（live coding，含预期输出）
7. 课堂练习 + 参考答案
8. 勘误与易错预警（回指 00-审阅报告 的条目号）
9. 课后作业（基础 / 进阶 / 挑战）
10. 考核点（可观测行为）
11. 延伸阅读 + 下一课预告
```

**三级难度标记**（修正审阅条目 C4）：**【必知】** 日常与考核都用 ／**【进阶】** 能读懂即可 ／**【工程】** 生产环境才需要。

```
00-基础语法/
```

- **教案是"怎么教"，讲义是"教什么"**：两者并存。教案每篇头部都标注了对应的讲义文件与示例目录，可以直接对照使用。


## 六、验证边界（诚实声明）

本教案在**没有 Go 工具链、且沙箱无外网**的环境下编写：

```text
$ go version
bash: go: command not found
$ curl -sI https://go.dev/dl/
curl: (35) OpenSSL SSL_connect: SSL_ERROR_SYSCALL
$ apt-get install -y golang-go
E: Unable to acquire the dpkg frontend lock ... are you root?
```

**因此：**

| 类别 | 状态 |
|---|---|
| 语言/库行为的断言 | ✅ 通过 `go.dev/ref/spec`、`pkg.go.dev/builtin`、`pkg.go.dev/encoding/json`、`pkg.go.dev/google.golang.org/grpc` 原文核对 |
| 数值类断言（`2^53` 边界、`strings.Count` 结果） | ✅ 用 Python 实际计算复核 |
| 代码逻辑推演（defer 经典题、Worker Pool 求和） | ✅ 逐行推演 |
| 仓库事实（文件大小、包名、import、原文行号） | ✅ 全部来自实际执行的命令输出 |
| **`go build` / `go vet` / `go test` 是否通过** | ❌ **未执行**——请在合并前用上面 §5 的命令跑一遍 |
| **示例代码中的 `ns/op`、`allocs/op`** | ❌ 全部沿用讲义的历史数据并标注为"仅供参考"，**未新增任何未经实测的数字** |

`00-审阅报告.md` 末尾有完整的「已验证 / 未验证」清单。**任何标注为"未验证"的内容，都请在你的机器上跑一遍再上课堂。**

## 七、给教师的三条使用建议

1. **先读 `00-审阅报告.md` 再备课**：知道哪些地方"讲义是错的"，比多准备两个例子更重要——学生会拿着讲义问。
2. **把 §7 课堂练习当堂做完**：这套题都是"预测输出"或"找错"，比听讲更能暴露误解。
3. **从第 06 篇起强制 `_test.go`**：Go 的工程习惯是靠工具链养成的，`gofmt` / `go vet` / `go test` 三件套从第三周开始就不能松。
